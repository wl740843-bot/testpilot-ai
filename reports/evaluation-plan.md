## 二、评估标准（5 个维度，判断口径固定）

对每一条需求，只按下面 5 个维度记录，保证 20 条判断一致：

| 维度 | 判断规则 |
| --- | --- |
| 格式通过 | 程序校验结果：`generate_cases_with_llm` 返回 `ok=True` 记"通过"；`ok=False` 记"不通过"，并注明程序报错原因 |
| 覆盖情况 | 人工看用例内容：正常/异常/边界三类都覆盖且覆盖需求要点 = 优；缺一类 = 中；明显漏掉需求要点 = 差 |
| 预期结果可验证 | expected 是否为"可观测的具体结果"（如"页面显示登录成功并跳转首页"）；≥80% 用例可验证 = 优；50–80% = 中；<50% = 差 |
| 重复用例 | 是否存在两条用例测同一个点（步骤+预期几乎一样）：无 = 优；1–2 条 = 中；≥3 条 = 差 |
| 无依据假设 | 模型是否编造需求之外的功能（需求只说"登录"，模型假设有"验证码""短信"等）：无 = 优；少量合理补全 = 中；明显编造 = 差 |
